# OnTrack Voice — مساحات المدير والريسيلر والمستخدم

**قرار 2026-11-02:** منصة OnTrack يجب أن تتيح التحويل بين `مساحة المستخدم` ولوحة الإدارة لمدير المنصة وللريسيلر، وكذلك الرجوع من حساب عميل في وضع الدعم بدون تسجيل خروج أو فقدان السياق.

## التنفيذ
- `console_can_switch_view` يمنح واجهة التبديل فقط لمالكي ومديري حسابات المنصة والريسيلر، ويرفض حسابات العملاء والعاملين غير الإداريين وأي جلسة دعم نشطة.
- `console_view_mode` يحتفظ بخيار `admin/user` في الجلسة، ويعرض قوائم المستخدم للعملاء أثناء معاينة المدير/الريسيلر دون تبديل الهوية أو الحساب فعليًا.
- زر دائم في Sidebar (خارج الجزء القابل للتمرير) وزر أعلى الشاشة، مع دعم الموبايل.
- الدخول لحساب عميل عبر الدعم يعرض زر رجوع للمنصة أو الريسيلر الأصلي، ويستعيد وضع المعاينة السابق تلقائيًا عند العودة.
- تغيير العضوية والحساب يزيل خيار المعاينة القديم، وسجل التدقيق يثبت التبديل.
- وضع `user` هنا معاينة تصميمية/تشغيلية للوحة المستخدم من نفس حساب المالك، وليس انتحال مستخدم آخر أو تغيير لصلاحياته. وضع الدعم منفصل ومقيّد بالمنشأ والسياسات الحالية.

## الاختبار
`php tools/test_workspace_role_switch.php` يفحص platform + reseller + support + منع manager/customer، وجود أزرار العودة والـPOST الصحيح، وحجب قوائم الإدارة أثناء معاينة المستخدم.

النشر يتطلب مرور workflow العام، ثم إثبات receipt من عامل السيرفر. لا تعتبر GitHub CI أو إنشاء release job إثباتًا لوصول الملفات إلى الهوست.
