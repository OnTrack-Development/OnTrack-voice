# إضافة المالك: الرد على السوشيال وTelegram

التاريخ: 29 أكتوبر 2026. طلب المستخدم الرد على كل السوشيال ميديا وتيليجرام. أضيف ذلك كنطاق قنوات متعدد قابل للتوسع، وليس كتكاملات متصلة بالفعل.

## تجربة العميل المطلوبة

يربط حسابات أو صفحات أو بوتات شركته بالقنوات المتاحة، ويعين إيجنتًا ومعرفة ومهمة وصلاحيات لكل قناة. تظهر المحادثات في Inbox موحد مع تصفية حسب القناة والحساب. تشمل الردود الرسائل الخاصة والتعليقات وmentions التي تسمح الواجهة الرسمية باستقبالها والرد عليها. يبقى عزل الشركات وhuman takeover والتدقيق والاستهلاك مطبقًا.

## مصفوفة أولية — ليست شهادة دعم نهائي

| القناة | النطاق المطلوب | الحالة |
|---|---|---|
| Web Widget | محادثة الموقع والمعرفة والأفعال | مواصفات سابقة؛ التطبيق الجديد لم يبدأ. |
| WhatsApp الرسمي | Inbox ورسائل وقوالب ووسائط حسب Meta | المواصفات الثلاثية وpause محفوظة؛ لا اتصال حي جديد. |
| Telegram | Bot API للخاص والمجموعات وفق الصلاحيات، وbusiness connection حيث يؤهل الحساب | وثائق Bot API وFAQ راجعت؛ لا بوت متصل هنا. |
| Facebook Pages/Messenger | رسائل الصفحة والتعليقات والردود المتاحة | مرشح؛ يلزم تدقيق حساب وأذونات وسياسات API. الوثائق أعادت 429 في هذه المراجعة. |
| Instagram | رسائل الحساب المهني وتعليقات وmentions وفق API | مرشح؛ لا وعد لحساب شخصي أو لجميع الأفعال؛ مراجعة Meta المباشرة توقفت عند 429. |
| X/YouTube/LinkedIn/TikTok وغيرها | adapters للأفعال المتاحة رسميًا | اكتشاف قدرات وتكلفة وأهلية قبل وعد التنفيذ، وليست دعمًا كاملًا مثبتًا الآن. |

## عقد القناة

- registry بقدرات مستقلة: استقبال وإرسال DM، والتعليقات والردود وmentions والوسائط والأزرار وحالة التسليم والقراءة. لا تعرض أفعالًا غير مدعومة وكأنها تعمل.
- credentials مشفرة ومملوكة للشركة، منفصلة عن AI upstream، مع ربط ملكية القناة بالحساب الخارجي.
- connect draft ثم test credentials/ownership ثم webhook verification ثم وارد فعلي ورد مؤكد ثم activation. لكل قناة revoke/disconnect/health وrate limits ونافذة رد خاصة بها.
- incoming events وoutbox بمعرفات idempotency ومحاولات تسليم وأخطاء منقحة، دون رسائل مكررة.
- توحيد Inbox لا يخلط هوية المحادثات أو الشركات؛ ربط شخص عبر قناتين يحتاج تحققًا لا تخمينًا.
- سياسات human pause تحدد حسب القناة. مدة 15 دقيقة المعتمدة في الحزمة تخص WhatsApp؛ لا تعممها إجباريًا على كل منصة دون سياسة واضحة.
- واجهات رسمية؛ لا scraping أو جلسات حسابات شخصية كبديل افتراضي لربط القنوات.

## Telegram: الدليل وحدوده

الـBot API يوفر webhook لاستقبال Update وsendMessage للرد، مع webhook secret وتحديثات تحتاج deduplication. الـFAQ يميز ما يراه البوت في الخاص والمجموعات حسب الإدارة وprivacy mode. business connection اختياري بحقوق يمنحها مالك الحساب، وليس إذنًا عامًا لكل chat.

المصادر الرسمية:

- https://core.telegram.org/bots/api
- https://core.telegram.org/bots/faq
- https://core.telegram.org/bots/features

هذه القدرات تثبت إمكانية بناء adapter، ولا تعني أن بوتًا أُنشئ أو أن webhook ورد AI اختبرا لدينا. لم نرسل رسائل أو نربط حسابات خارجية في التجهيز الحالي.

روابط Meta الرسمية أدناه أعادت 429 عند محاولة القراءة؛ يلزم مراجعتها قبل تثبيت شروط الأذونات ونوافذ الرد الخاصة بالإصدار:

- https://developers.facebook.com/docs/messenger-platform/
- https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/messaging-api/

## قبول التنفيذ لاحقًا

لكل قناة: عزل tenant A/B، وربط وإلغاء، وcredentials/signatures خاطئة، وduplicate events، ورد وتسليم، وrate limit/retry، وhandoff suppression، وبقاء القنوات الأخرى تعمل، وتقرير موثق. نجاح Telegram لا يثبت صوت SIM أو العكس.
