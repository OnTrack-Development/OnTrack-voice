## مصدر وتوقيت التقارير

التقارير JSON خام قُرئت من الفرع التشغيلي `ontrack-host-link`. هي صادرة عن العامل بحساب appontrack؛ وقتها UTC. تاريخ29أكتوبرالقاهرة يطابق ليلة28أكتوبرUTC. روابطها في main نسخة محفوظة؛ للنتائج اللاحقة اقرأ الفرع الحي.

المخرجات النصية المحلية توضح أنها local test أو إعادة حفظ لمخرجات ظهرت في هذه الجلسة، وليست جلسة SSH ناجحة أو تسجيلًا جديدًا للهاتف. لا يوجد ملف تسجيل مكالمة أو dump صوت في هذه الحزمة.
