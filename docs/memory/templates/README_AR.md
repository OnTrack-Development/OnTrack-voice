# قوالب الإدخال

القوالب JSON وليست أحداثًا منفذة. انسخ القالب واملأه ببيانات فعلية ثم أضفه إلى سجل JSONL المناسب، أو أنشئ/حدث issue مع history. null يعني المعلومة غير متاحة، ولا يعني نجاحًا.

أمثلة القوالب: action.json، attempt.json، issue.json، test.json. كل الأوقات UTC وتعرض للمالك بتوقيت Africa/Cairo عند الحاجة. لا أسرار في أي حقل، بما فيها command و error.
