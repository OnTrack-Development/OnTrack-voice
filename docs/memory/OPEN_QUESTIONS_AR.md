# أسئلة مؤجلة تحتاج قرار المالك

> تُجمع أثناء التنفيذ دون إيقاف العمل، وتُعرض على المالك في نهاية الجلسة.

## 1. قاعدة البيانات
- الحساب `appontrack` لا يملك بيانات اعتماد MySQL/عبر تاريخ `~/.my.cnf` (Access denied بدون password).
- **القرار المطلوب:** إنشاء قاعدة بيانات MySQL مستقلة للتطبيق (اسم + مستخدم + كلمة مرور) عبر cPanel، أم البدء بـ SQLite مؤقتًا داخل `saas` مع التوثيق أنه غير مخصص للإنتاج؟

## 2. النشر والنطاق العام
- التطبيق سيكون في `/home/appontrack/public_html/saas/public` ولا ننشر فوق الديمو الرئيسي.
- **القرار المطلوب:** النطاق العام المقصود للمنصة (مثال: `saas.ontrackegy.com`؟) وهل يوجد SSL جاهز له؟ وهل يبقى الديمو الحي في الجذر كما هو نهائيًا؟

## 3. بيانات اعتماد النظام التجاري / AI
- حسب القرار الحاكم، OnTrack فقط تضيف AI providers من `/control/*`؛ لا BYOK للعميل.
- **القرار المطلوب عند مرحلة Provider Hub:** هل نملك حتى الآن مفاتيح Google Gemini أو Custom upstream للتكامل الفعلي، أم نبني الواجهة والإعدادات المشفرة ونترك `CONNECTION_PENDING` بانتظار مفاتيح تُدخل من لوحة `/control` فقط؟
