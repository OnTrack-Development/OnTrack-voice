# OnTrack Voice v1.0.0 — العقد التنفيذي للمرحلة الأولى
**تاريخ الاعتماد للمواصفات:** 2026-11-06. **الحالة:** تنفيذ جزئي، اختبار ونشر لم يثبتا بعد.
**الموقع:** app.ontrackegy.com؛ **الجهاز المرجعي:** Xiaomi Note 12 Pro 5G.
**مصدر الحقيقة:** آخر قرارات المالك في جلسة نوفمبر 2026 تتقدم على خارطة نوفمبر 3 فيما يتعلق بنطاق المرحلة الأولى.

## 1) خط الأساس والدليل
- صاحب المشروع يؤكد أن **ربط حساب الأدمن الحالي يعمل** من التجربة الأولى ولم يُفك؛ لا تعاد التهيئة ولا يُحذف pairing/token/data بلا داع.
- صاحب المشروع يؤكد **أن الرد التلقائي والكتم يعملان جيدًا**. الصوت مستقر وجيد على Wi-Fi، وعلى 4G يوجد تكدس/تأخير وميل للإطالة؛ لا تعلن أن الاثنين معطلان اعتمادًا على تقرير تاريخي.
- Gemini Live يعمل صوتيًا لكن تحسين turn-taking وتقليل الإطالة ومنع هلوسة التفريغ لم يُغلق باختبار قبول.
- يوجد محرر Flow رسومي، لكنه غير كافٍ في التنفيذ الذكي؛ السيناريو النصي المفصل يعطي نتائج أفضل حاليًا.
- Knowledge Base المطلوبة (مجلدات + PDF/DOCX/TXT/MD + معالجة وتعارضات ومزامنة/API caching) **غير مكتملة**؛ وجود مخزن chunks سابق لا يحقق مواصفات المستخدم.
- تكامل العمليات الحقيقية (WHMCS/Laravel/حجوزات) **غير منفذ End-to-End**؛ أدوات وWebhooks عامة لا تعني أن الحجز أو التذكرة يعملان عبر مكالمة.
- سجلات مكالمات أولية موجودة، لكن **ملخصات سياقية ونتائج إجراءات منظمة غير مكتملة**.
- لا يثبت أي إصدار منشور قبل تطابق SHA، CI، host receipt، وتجربة SIM فعلية.

## 2) ما يجب تسليمه في إصدار واحد v1.0.0
### A — الجهاز والمكالمات
- الإبقاء على SIM وصوتها كما هما دون تغيير المسار العامل بغير اختبار رجعي.
- الموبايل = جسر تحكم/صوت. الأزرار الدائمة: تشغيل/إيقاف، حالة الشريحة والإيجنت وتعيين المصدر، صلاحيات التشغيل، تحديث التطبيق، فتح لوحة الويب **في المتصفح الخارجي**.
- معالج أول تشغيل فقط عند عدم اكتمال الجاهزية؛ ربط الحساب، الأذونات الأساسية، خيارات إعداد الجهاز الضرورية (Wireless/USB debugging حسب آلية الجهاز)، اختبار readiness. عند نجاح الإعداد لا يعيد إزعاج المستخدم؛ يظهر «إصلاح التفعيل» فقط عند مشكلة فعلية.
- التفعيل المتكرر عند كل دخول غير مقبول؛ حفظ الربط الحالي والتعامل مع فقد اتصال Debugging عند تغير الشبكة أو إعادة تشغيل الجهاز دون ادعاء أنه دائم.
- إثبات الرد التلقائي، mute وunmute، وصول PCM ثنائي الاتجاه، المقاطعات، إنهاء مكالمة الشريحة الفعلي، التعافي من التغيير بين Wi-Fi و4G، من غير Accessibility.
- معالجة تكدس 4G: bounded jitter buffer، drop stale audio، قياس transport/RTT/VAD/queue latency، إعادة تزامن منضبطة، عدم الانتظار حتى ينتهي الصوت القديم. عدم فقد سياق المكالمة.
- تقليل ثرثرة الإيجنت، الاستماع حتى انتهاء دور العميل، مصرية طبيعية، عدم الاعتراف بأنه سيناريو، لا حقائق مختلقة.

### B — العقل ومصادر المعرفة
- Knowledge Base مستقلة لكل Tenant/Site/Agent بفولدرات وملفات PDF/DOCX/TXT/MD/روابط مع versioning، validation، dedupe، conflicting-source review، crawl provenance، index status، update scheduling/trigger.
- مصدران رسميان للمعلومة: ملفات/محتوى محلي موثق، وواجهات API حيّة. تُخزّن البيانات شبه الثابتة مع TTL/source priority؛ معلومات الحجوزات والفواتير والحالات الحرجة تُراجع حيًا قبل تنفيذ أو تأكيد.
- لا يُقال «تم» لأي طلب إلا بعد تلقي نجاح API مع معرف العملية الحقيقي، وتسجيل idempotency/audit.
- Flow Builder: Intent/Reasoning/Knowledge/Tool/Validation/Approval/Fallback nodes، Draft/Test/Publish/Rollback، إصلاح Invalid node type، محاكاة واختبارات وtrace لكل انتقال؛ السيناريو النصي المفصل يظل مسارًا صالحًا مستقلًا.

### C — التكاملات
- Integration Manager يدعم Generic REST/OpenAPI/Laravel/WHMCS، أسرار مشفرة بالهوست، scope/allowlists، تجارب اتصال، صلاحيات قراءة/كتابة وسياسات موافقة، منع SSRF والتصرف من model وحده.
- حجز العيادة: المواعيد المتاحة -> بيانات الاسم والهاتف -> قراءة تأكيد -> حجز API -> معرف الحجز وتوقيت الحضور من النظام. فشل الطلب لا ينتج تأكيدًا.
- WHMCS: تعرف هوية مع تحقق إضافي قبل بيانات حساسة؛ جلب خدمات/فواتير/أسعار وخطط؛ صياغة تذكرة وقراءتها للعميل؛ إنشاء بعد موافقة صريحة فقط؛ إضافة رد/متابعة. **ممنوع تعليق/حذف/إغلاق خدمة أو تذكرة تلقائيًا**.
- Laravel: discovery/schema mapping، الاستعلام والطلب والحجز بحسب العمليات المسموحة، مع تأكيد وتدقيق وتزامن الحالة.

### D — نتائج المكالمة
- Transcript مرتب ومتواصل نسبيًا، timing وspeaker labels لا fragment spam؛ تنقية الأخطاء من السياق دون اختلاق أسماء/أرقام.
- Summary سياقي موجز، intent/outcome، البيانات المجمعة، اسم العميل إن وثق، booking/ticket/invoice IDs، نجاح/رفض/تعذر، follow-up، طلب موظف دون تنفيذه تلقائيًا.
- Tool traces مستقلة عن ملخص العميل، أرقام حقيقية، event correlation، خصوصية وسجلات قابلة للمراجعة.

### E — أسرار المحرك ونسخة APK
- **قرار ملزم:** APK الأساسي لا يتضمن تنفيذ capture/injection/audio routing الحساس متى أمكن فصله تقنيًا. المحرك منفصل على السيرفر مع تحميل وحدات موقعة ومشفرة فقط بعد مصادقة وترخيص، والتحقق من checksum/signature والاستحقاق؛ تجنب وضع المصدر/البرومبت/المفاتيح في الحزمة.
- بروتوكول المحرك المحلي ومسار PCM وما يفرضه Android قد يبقيان قابلين للرصد؛ مجرد التحميل عند التفعيل لا يجعل نسخة المحرك الموجودة على جهاز العميل غير قابلة للاستخراج. شرط القبول: محاولة استخراج من **APK الأساسي وحده** لا تعطي الكود المنفصل، مع اختبارات تحليل ديناميكي مستقلة للمخاطر المتبقية.
- استخدم تشويش R8/Native عند ملاءمته، لا تسرب سجلات أو تعليقات/مراجع تحليل في الأصول الموزعة. لا تمس إشعارات تراخيص المصدر المفتوح الواجبة. لا تُحدث تلفًا متعمدًا لملفات جهاز العميل.
- توزيع APK ديناميكي من خارج Play خاضع لاختبارات توافق ومراجعة أمنية؛ يجب تحديد القنوات المدعومة قانونيًا وتقنيًا.
- لا تعطل محرك الصوت الحالي قبل بناء مسار بديل قابل للتحقق على نفس الهاتف.

### F — SaaS ولوحة التحكم
- التسجيل User/Reseller وخطوات الدخول واستعادة كلمة السر تعمل مع عزل tenants.
- إعداد Platform «إظهار الريسيلرز» (افتراضي enabled للمحافظة على الوضع): عند التعطيل تُخفى إدخالات الريسيلرز وروابط تسجيلهم وخططهم حتى من لوحة الأدمن. لا تمس الحسابات والاشتراكات القائمة ولا تفك أي ربط. يجب حماية POST والتحقق النهائي من التسجيل.
- واجهة العميل: Agents/Scenario/Flow/Knowledge/API/Calls/Devices/Settings بشكل واضح؛ تجنب إظهار الحملات والجدولة وإضافات الأصوات ومكالمات المدير والتحكم التقني المتكرر في نسخة v1.
- الادمن: الإعدادات الضرورية للحسابات والباقة والأمان والربط والتكاملات؛ عناصر Phase 2 تُحجب عن التنقل مع بقاء نسخة أرشيفية.

## 3) المرحلة الثانية (محفوظة وليست محذوفة)
الأصوات الإضافية واستنساخها؛ جدولة حملات الاتصال وتصدير جهات الاتصال وإعادة المحاولات؛ اتصال المدير تلقائيًا بعد الإغلاق؛ توسيع إنذارات التحويل البشري والـhandoff؛ WhatsApp/social/video integrations غير الضرورية لنسخة الهاتف الأساسية؛ تجارب الحمل 10–20 مكالمة في مرحلة توسيع السعة؛ أدوات تشخيص المطور الظاهرة للعامة.
**الاحتياطي المجمّد في فروع Git:** `archive/old-version-main-20261106` و`archive/old-version-active-20261106`. لا تُنقل أسرار أو ملفات هوست حية إلى public_html.
