# ربط الموقع بالموبايل — 0.1.4

أمر المالك الحالي هو الربط المباشر وتجربة الإيجنت، دون انتظار اختبار تسجيل منفصل. لا يثبت ذلك نجاح الصوت في الاتجاهين؛ نراجع الخطأ عند المكالمة الفعلية.

## المسار المنفذ في المصدر

- رابط التطبيق ثابت HTTPS إلى app.ontrackegy.com؛ لا تحويلات HTTP تلقائية ولا قبول رابط يسرّب مفتاح الربط إلى طرف آخر.
- لوحة /saas/mobile/ محمية بمفتاح تجربة لجهاز واحد، مع session cookie وCSRF. تغيير المهمة والصوت وقناة الإدخال، وتشغيل/إيقاف والرد التلقائي، وآخر heartbeat. ليس نظام شركات متعددة أو إدارة حملات مكتملًا.
- device.php يسلم إعدادات السيرفر كل5ثوانٍ. session.php يتحقق من مفتاح الربط ويستخدم api/live_session.php الحالي ومفتاح Gemini وقاعدة معرفته على السيرفر. يصل الهاتف توكن مؤقت فقط.
- تعديل ضيق في live_session.php يتيح للـwrapper الموثوق تمرير نوع الجلسة وتعليمات المهمة؛ طلب المتصفح العادي يبقى بنفس المسار. لا قراءة أو نشر config.php أو config.json أو مفاتيح قديمة.
- foreground service يقرأ حالة الشريحة من المساعد المحلي؛ يطلب إجابة الوارد عند تفعيلها، أو يتصل المالك من تطبيق الهاتف أثناء تفعيل الربط. طلب الاتصال من حملة/قائمة لم يُنفذ هنا.
- جلسة PCM محلية موثقة من المساعد:48k/stereo إلى التطبيق؛ اختيار right افتراضيًا ثم تحويل16k/mono إلى Gemini. رد GeminiPCM24k يُحوّل48k/mono ويحقن في نفس مسار music/screening المجرّب. لا تشغيل عبر سماعة الغرفة ولا getUserMedia.
- جسر واحد يملك الالتقاط؛ يُوقف وضع تسجيل الملفات أثناء الربط لتجنب AudioRecord متنافس. زر اختبار الملف يرفض العمل بالتزامن مع خدمة الربط.
- يدعم JSON text/binary WebSocket ورسالة المقاطعة ومسح طابور الصوت، مع حدود لطوابير النقل. يُغلق الجسر وتستعاد حالة الميكروفون عند إنهاء الجلسة.
- أصوات Gemini الحالية للردود الحية؛ ملف الصوت المستورد ظل إثبات حقن، ولا يُدعى استنساخ كل رد. محول الصوت المستنسخ القائم يحتاج ربطًا منفصلًا إذا لم يكن هو محرك الموقع الحالي.

## النشر والتحقق

ساعة إعداد هذا الملف لم يُنفذ النشر الحي: مهمة host-link للقراءة لم تعد تقريرًا، وSSH رجع Network is unreachable. طلبنا تشغيل العامل المثبت مرة واحدة دون PAT جديد أو قراءة اعتماده. المصدر وجهّز deploy.py:payload مضغوط ومثبتSHA256، يتحقق من UID2379، يفحصPHP، ويحفظ backupخاصًا، وينشر فقط ملفات saas/mobile وتعديل الجلسة المحدد. لا إعادة تثبيت للعامل ولا مسح للموقع.

0.1.2 الاحتفاظ بالتسجيل نجح في CI run41117754860؛ أول بناء0.1.3 run41119463261 نجح أيضًا. البناء النهائي بعد استقبال binary frames وسياسة الالتقاط يحتاج نتائج CI الخاصة به. لا تعتمد على run أقدم لتصف الملف النهائي.

## ما يزال معلقًا

الوصول التنفيذي للهوست، نشرHTTPوفحص401/المصادقة/جلسةGemini، ثم مكالمة AI فعلية. بوابة PENDING_DEVICE_AUDIO_PROOF العامة باقية. التشغيل بعد reboot قبل أول unlock، ومهلة Android dataSync، وإصدارات المصنع/الشريحة، وحملات وجدولة وعزل tenants ليست مثبتة. النسخة المباشرة الحالية اختبار تكامل لجهاز واحد. مفتاح تجربة جديد تولد محليًا؛ يُحفظ hash فقط في مصدر النشر، ولا تُرفع قيمته إلى GitHub أو تقارير الهوست.
