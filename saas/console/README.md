# OnTrack Voice SaaS console

PHP 8.1+ (target 8.3), PDO SQLite for isolated demo and PDO MySQL for production.
Public entry: `/saas/console/` with route `/login`.
Private state outside document root: `/home/appontrack/.ontrack-saas/`.
Bootstrap installer (host CLI): `/opt/cpanel/ea-php83/root/usr/bin/php saas/console/database/Seed.php`.

This application provides tenant-scoped Admin/Reseller/User portal, branded account views, site-specific AI drafts & KB, plans, account staff, voice grants, demo calls/campaigns, named revocable API keys, and signed webhook for WHMCS/Laravel pending order plus verified payment events. It does **not** yet provide a full production dialer integration, custom DNS/TLS provisioner, payment-provider-side independent live verification, or automatic outbound WHMCS email from this host. These are explicitly identified integration gates.

Admin demo login is generated by seeder; secrets are never stored in plaintext in GitHub.
Do not deploy `AGENTS.md` or `docs/` or `ops/` under the public web root. Never mix the existing `/saas/mobile/` bearer identity with tenant-level tokens.

## Android SIM pairing — six digits, no QR required

1. Log in to the appropriate account and open `/saas/console/?tab=devices`.
2. Under **ربط الشريحة في 3 خطوات**, choose a site, published agent and **SIM 1** or **SIM 2**, then select **إنشاء كود الربط (6 أرقام)**.
3. Enter the displayed six-digit code (including leading zeros) using **ربط SIM 1 / ربط SIM 2** in the OnTrack Android app. It expires after ten minutes and cannot be reused. This enrollment is account/SIM scoped; no QR, pilot bearer or manually entered provider API key is required.

Source change alone is not host or APK deployment proof. The new six-digit entry requires a native Android release built from this branch, signed with the existing certificate and installed by Android. Existing 24-character tickets may be redeemed by their compatible old client until expiry. Verification of the physical SIM/audio path remains separate from successful account pairing.
