# OnTrack Voice — قائمة تسليم الديمو الملزمة (Android + app.ontrackegy.com)

**المرجع التنفيذي المعتمد:** طلبات المالك في 31 أكتوبر 2026. **النطاق الحالي:** إكمال تطبيق Android والديمو على `app.ontrackegy.com` فقط، **لا بدء SaaS المنتج** حتى نجاح دورة E2E.  
**الحالة:** OPEN — هذه القائمة مرجع الإقفال الرئيسي؛ مراجعة الفجوات: `docs/mobile/VOICE_CALL_FEATURE_GAP_AUDIT_2026_10_31_AR.md`.

## قاعدة الإقفال والمحاسبة

- `[ ]` = **غير مكتمل** مهما كان عدد الملفات أو الصفحات التي بُنيت. **لا تتحول إلى `[x]` إلا مع commit + اختبار + دليل تشغيل فعلي** موثق بجوارها.
- يُسمح بتسجيل تقدم جزئي في سجل التنفيذ، **دون** تحويل المهمة إلى DONE. PASS في unit tests لا يعني نجاح مكالمة على الجهاز.
- عند كل تسليم: حدث هذه القائمة و`docs/memory/CHECKPOINT.md`، وضع مرجع الاختبار والنسخة المثبتة ونتيجة الهوست والجهاز.
- لا حذف بيانات Android أو الاقتران ولا إيقاف Play Protect أو فتح ADB على الشبكات دون موافقة وتجربة اختبارية. لا تغيير للمسار الصوتي العامل `mix` دون إثبات بديل.
- لا تكرار نشر أو تنفيذ وظيفة على GitHub/host-link إذا كان هناك job معلّق. أسرار/مفاتيح/تسجيلات وبيانات العملاء لا توضع في المستودع.
- التصنيف: `CODE` للكود فقط، `CI` لاختبار آلي، `HOST` للنشر والخدمات، `DEVICE` لتجربة Xiaomi، `E2E` لدورة فعلية. الإغلاق يحتاج العناصر المرتبطة بالمهمة.

## P0 — ثبات الهاتف والتحديث ومسار بيانات الشريحة

- [ ] **VC-P0-01 — Android Native OTA:** تنزيل واحد لملف APK الموقّع، استكمال من cache، عدم تكرار جلسة التثبيت، إظهار الموافقة/الإلغاء/النجاح/الخطأ، عدم التثبيت أثناء المكالمة. **قبول:** CI + اختبار تثبيت تحديث فوق النسخة الحالية على Xiaomi بلا مسح بيانات، وتطابق رقم الإصدار بعدها.
- [ ] **VC-P0-02 — واجهة OTA:** تحديث HTML موقّع، rollback، لا يقطع المكالمة، وعدم إظهار أدوات Native غير مدعومة قبل تثبيت APK المناسب. **قبول:** تحديث فعلي على جهاز المالك ونسخة `revision` وتأكيد rollback.
- [ ] **VC-P0-03 — Wi-Fi/4G/5G:** الاتصال بموقع OnTrack عبر بيانات الهاتف، مع جسر صوت SIM ثنائي الاتجاه أثناء إغلاق Wi-Fi. **قبول DEVICE:** مكالمة واردة وصادرة تتبادلان الكلام على 4G/5G؛ تعافٍ بعد قطع الشبكة؛ اختبار restart منفصل.
- [ ] **VC-P0-04 — Wi-Fi-free ADB risk:** مسار `Start without Wi-Fi` opt-in فقط مع شرح منفذ 5555، اختبار نجاح/فشل الإعداد، إيقافه وإثبات غلق المنفذ؛ ممنوع تفعيله افتراضيًا أو اعتباره حل إنتاج آمن قبل تقييمه.
- [ ] **VC-P0-05 — استقرار الخدمة:** استئناف الخدمة تلقائيًا ضمن حدود Android، فصل الاتصال عن تشغيل AI، تزامن التشغيل/الإيقاف مع الموقع، عدم الرد مرتين، عدم إعادة وصل AI بمكالمة استلمها موظف. **قبول:** DEVICE + HOST وإعادة تشغيل التطبيق وتبديل الشبكات.

## P1 — سجل المكالمات وجهات الاتصال

- [ ] **VC-P1-01 — Call ID وأحداث الهاتف:** معرف فريد للمكالمة؛ بدء/رنين/رد/انتهاء/فشل/لم يرد؛ اتجاه المكالمة حيث يمكن إثباته؛ معرف الجهاز والحملة اختياري؛ timestamps ومدة دقيقة؛ idempotency/retry مع فقد الشبكة.
- [ ] **VC-P1-02 — Call History:** سجل ظاهر **على الهاتف والموقع** مع فلترة حسب الوقت/الاسم/الرقم/النتيجة/الوكيل/الحملة؛ كل مكالمة بما فيها الفاشلة أو التي لم يرد عليها العميل.
- [ ] **VC-P1-03 — الهاتف Contacts:** زر استيراد **كل** جهات الاتصال أو **اختيار بعضهم** بإذن Android واضح، عرض اسم ورقم، dedupe وتطبيع أرقام مصر والدولي، عدم رفع أي أرقام قبل التأكيد.
- [ ] **VC-P1-04 — إدخال واستيراد الملفات:** CSV/XLSX/TXT ولصق `الاسم,الرقم` أو رقم في كل سطر؛ معاينة/إصلاح/استبعاد غير الصالح والمكرر، وحفظ أسماء العملاء؛ دعم تحديث القائمة بدلاً من تكرارها.
- [ ] **VC-P1-05 — DNC وخصوصية:** لا تتصل مجددًا / رفض التواصل / رقم محظور مع منع الاتصال قبل كل محاولة، وصلاحيات الوصول والموافقة وسجل سبب الإدراج.

## P2 — جدولة الحملات والتنفيذ من الهاتف

- [ ] **VC-P2-01 — Campaign Builder:** إنشاء حملة واختيار الوكيل والسيناريو وقائمة الأرقام ووقت البدء/الانتهاء وأيام العمل والعطلات والمنطقة الزمنية ومهلة الفصل بين المكالمات.
- [ ] **VC-P2-02 — Android Executor:** الموقع يرسل دفعات العمل المصرح بها، **الهاتف ينفذ** dial/end/delay/next-number على خط SIM مع سجل حالات متسلسل دون Accessibility؛ server يحتفظ بسياسات الإيقاف/الملكية/lease.
- [ ] **VC-P2-03 — التحكم:** بدء/إيقاف مؤقت/استئناف/إلغاء، إيقاف فوري، عدم الاتصال مرتين عند retry أو شبكة ضعيفة؛ backoff وحد أقصى محاولات، أرقام Do Not Call مستبعدة.
- [ ] **VC-P2-04 — تقرير الحملة:** حالة كل رقم، المحاولات، إجمالي المكالمات والردود والتحويلات والرفض وجودة المكالمات دون أرقام مختلقة.
- [ ] **VC-P2-05 — إثبات مكالمة صادرة:** Android→SIM→عميل حقيقي بإذن واضح، ثم مكالمة تالية بعد الفاصل؛ E2E من اللوحة إلى السجل.

## P3 — AI Scenario Generator وAgent Builder

- [ ] **VC-P3-01 — مولد السيناريو:** حقول الشركة والمجال والخدمات والأسعار والعملة وأهداف المكالمة والاعتراضات والخصومات المسموح بها واللغة والنبرة والافتتاحية، وزر Generate بالـAI.
- [ ] **VC-P3-02 — مراجعة/اعتماد/نسخ:** مسودة قابلة للتعديل، معاينة قبل الاتصال، versioning واختبار السيناريو ومنع الأسعار/الوعود غير المعتمدة.
- [ ] **VC-P3-03 — متغيرات العملاء:** `{{contact.first_name}}` و`{{contact.full_name}}` و`{{contact.phone}}` والمتغيرات المعتمدة، تتغير لكل رقم، fallback محايد عند غياب الاسم، لا اختلاق/خلط بيانات.
- [ ] **VC-P3-04 — Agent Builder العامل:** إنشاء عدة وكلاء وشخصية/صوت/تعليمات/معرفة/قواعد اعتراض وتصعيد، تعيين الوكيل لحملة؛ ربط Flow Builder فعليًا بصوت الهاتف لا مجرد Canvas.
- [ ] **VC-P3-05 — إدارة المعرفة:** رفع مصادر معتمدة، تحديثها، وربط إجابة AI بالمصادر وعدم استخدام أي معلومة غير مؤكدة عن عروض/أسعار الشركة.

## P4 — Live Monitor والتسجيل وتقارير الجودة

- [ ] **VC-P4-01 — سماع AI أثناء المكالمة:** مسار مراقبة منفصل يحافظ على صوت AI للعميل، مع قياس echo/latency ولا يكرر الصوت في المكالمة.
- [ ] **VC-P4-02 — تسجيل الطرفين:** Client + Agent في مسارين موثقين أو mix موحد عند السماح الفني والقانوني؛ إثباتهما على Xiaomi، حالة التسجيل واضحة، صلاحية وصول وموافقة وتشفير وحذف آمن.
- [ ] **VC-P4-03 — تدخل المشرف:** متابعة حية وTranscription حيث يثبت، استلام بشري للمكالمة الحالية فقط، إيقاف AI، ومنع عودته لنفس المكالمة بعد الاستلام.
- [ ] **VC-P4-04 — التقرير التلقائي بعد كل مكالمة:** اسم/رقم/بداية/انتهاء/مدة/حملة/وكيل/ملخص/نتيجة/اعتراضات/خطوة تالية، مع حالة `unavailable` إذا لم يتوفر دليل صوتي.
- [ ] **VC-P4-05 — Quality Center:** راضٍ/غير راضٍ/مهتم/غير مهتم/لا تتصل مجددًا، درجة جودة **تقديرية** مدعومة بتفريغ أو دليل، مراجعة الموظف وتصحيح التصنيف، تقارير المقارنة بين الإصدارات.

## P5 — واجهة OnTrack احترافية وأساس النقل المستقبلي

- [ ] **VC-P5-01 — هوية حقيقية:** جلب شعار OnTrack الأصلي وأيقونة launcher/favicon المعتمدة وخطوط وألوان التصميم **من الأصول الموثقة** (لا ألوان متخيلة أو شعار OT نصي).
- [ ] **VC-P5-02 — Android UI:** صفحات Dashboard/Calls/Campaigns/Monitor/Settings منظمة، حالات فارغة، RTL/LTR، Dark/Light، رسائل أخطاء واضحة، تفاعل سريع، بدون أزرار صورية.
- [ ] **VC-P5-03 — Web demo UI:** لوحة إدارة متجانسة مع الهاتف، Agent Builder، Campaigns، Contacts، Call History، Quality Center.
- [ ] **VC-P5-04 — فصل المعمارية:** عقود API للأحداث والهوية والصلاحيات والبيانات، وحدات قابلة للنقل للـSaaS بدون نسخ منطق المكالمات/الـAI، واختبارات عزل مستقبلية.
- [ ] **VC-P5-05 — E2E DEMO SIGN-OFF:** من إعداد وكيل وسيناريو ورفع الأسماء والجدولة إلى مكالمات واردة وصادرة على بيانات الهاتف ثم تسجيل/تقرير/جودة/DNC/استئناف/OTA؛ سجلات حقيقية، فحص أصوات وتوقيتات وخصوصية. **بعد هذه النقطة فقط** تُفتح مرحلة SaaS.
