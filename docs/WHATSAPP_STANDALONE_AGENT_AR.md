# OnTrack Voice · WhatsApp AI Support مستقل
**قرار المالك: 2026-11-02** — عبارة «زي AI Support Agent بتاع WHMCS» تعني **نفس طريقة العمل والتجربة** (الرد والتصرف والواجهة والأزرار والتحويل البشري)، ولا تعني الربط أو الاعتماد عليه. التوجيه القديم بأن WHMCS هو محرّك WhatsApp الوحيد مُلغى.

## حدود النظام
- المحرك الأساسي هو **OnTrack Native Support Agent** داخل OnTrack Voice. لكل رقم Meta قناة مستقلة وموقع وإيجنت منشور داخل حسابه. لا يُطلب تثبيت أو تشغيل WHMCS.
- WHMCS وLaravel وقاعدة المعرفة والملفات مصادر تكامل اختيارية لاحقًا، وليست prerequisites. وجود بيانات WHMCS لا يتيح قراءة الحساب بناءً على رقم الهاتف وحده.
- نفس صندوق الوارد للعميل والموظف والـAI، Meta text وinteractive quick replies؛ رد الموظف يوقف AI مدة 15 دقيقة للمحادثة فقط؛ ويمكنه استلامها دائمًا حتى فك القفل.
- تعطيل AI **افتراضي** لكل اتصال جديد؛ لا يفعّله المالك إلا بعد اختيار إيجنت منشور واختبار إعدادات Meta ووجود مزود OnTrack، والرد بدون AI يظل متاحًا.
- معالجة الاستقبال عبر webhook بتوقيع SHA-256، dedupe بمعرّف Meta، ثم إنشاء مهمة AI منفصلة؛ الرسائل الواردة لا تنشئ فواتير أو تذاكر أو عملاء.
- Native agent يقرأ تعليمات ومعرفة **نسخة منشورة** من Agent Studio، وسجل المحادثة؛ يرسل مسودة للذكاء، ثم يطلب موافقة مراجعة منفصلة على **نفس النص**؛ إذا فشلت المراجعة أو غابت البيانات يتوقف/يحوّل لبشري. لا تنفيذ تلقائي لأوامر CRM.
- قبل أي إرسال، يراجع توقف الموظف والجيل الحالي للمحادثة، واختبار Meta، ونافذة خدمة العملاء 24 ساعة. قبول Meta لا يساوي تسليمها.
- الأزرار السريعة البشرية المضافة حاليًا بحد أقصى ثلاثة خيارات في الرسالة. ربطها التلقائي بإجراءات Flow Builder وإرسال أزرار AI وفق المسارات **غير مثبت بعد** ويحتاج مسار تنفيذ/اختبار إضافي.

## الملفات المتأثرة بهذا الفرع
- saas/console/_core/WhatsAppNativeAgent.php: Native provider + reviewer + lifecycle.
- saas/console/_core/WhatsAppSupport.php: استقبال webhook + اختيار native job + interactive Meta buttons.
- saas/console/_core/Bootstrap.php: ترقية v19 لإيجنت القناة وحالة تفعيله (افتراضيًا غير مفعّل).
- saas/console/_core/Actions.php و Views.php: اختيار إيجنت، تفعيل وإيقاف، أزرار الموظف وواجهة مستقلة.
- saas/console/whatsapp-worker.php و whatsapp-webhook.php: dispatch native؛ Legacy WHMCS adapter اختيارى للحسابات القديمة ولا يُستدعى لمسار OnTrack.
- tools/test_whatsapp_native_agent.php: اختبارات نقل وهمية بدون إجراء اتصالات Meta/Google حقيقية.
