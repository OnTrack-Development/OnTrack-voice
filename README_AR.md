# OnTrack Voice v0.6.0

تطبيق مستقل على استضافة PHP 8.1+ مع HTTPS وامتدادات cURL وmbstring. يستخدم Gemini Live مباشرة من المتصفح بالموديل والصوت الموجودين، وتوكن مؤقت يصدره السيرفر. المفتاح يبقى في `api/demo_config.local.php` أو `config.php` القديم، ولا يوضع في Git.

## مكالمة صادرة بمهمة مخصصة

1. اختَر «مكالمة عميل من التليفون»، ثم «إعداد المهمة».
2. اكتب اسم الإيجنت والشركة ودوره، اسم العميل وسياقه، تفاصيل الشقة أو المنتج، السعر والعملة، شروط الدفع، الاعتراضات والردود، هدف المكالمة والافتتاحية. حد السعر الأدنى سري؛ تركه فارغاً يعني أن أي خصم يحتاج موافقتك. التفاصيل غير المذكورة تحتاج تأكيد المسؤول.
3. اضغط «اعتمد المهمة» ثم «جهّز الإيجنت». وافق على إذن مدخل الصوت. الإيجنت يتصل بالخدمة في صمت ولا يرسل صوت المدخل حتى التفعيل. بيانات المهمة تُرسل لخدمة الصوت عند التجهيز؛ لا تُحفظ على السيرفر ولا في localStorage، وإعادة تحميل الصفحة تمسحها. الصوت المختار فقط يحتفظ به المتصفح.
4. اتصل بالعميل يدوياً من Phone Link. بعد إجابة العميل اضغط «العميل رد — فعّل انتظار صوته». يبدأ الإيجنت بعد أول كلام مفهوم من العميل، باسمه والشركة من المهمة. لا يرسل التطبيق أمر تحية أون تراك في هذا الوضع.
5. «إيقاف الإيجنت» ينهي جلسة Gemini فقط؛ أغلق مكالمة الهاتف من Phone Link أيضاً. يمكن إعادة فتح نص المكالمة للمراجعة قبل تجهيز الجلسة التالية.

«تحميل مثال تجريبي» يملأ نموذجاً افتراضياً واضحاً للاختبار؛ استبدل كل بياناته قبل الاتصال الفعلي. المهمة مقفولة أثناء الجلسة؛ أوقف الإيجنت لتعديلها أو الانتقال لعميل آخر.

## توصيل الصوت على Windows / Voicemeeter Banana

| المسار | الإعداد |
| --- | --- |
| صوت العميل من Phone Link | إخراج Windows والاتصالات: `Voicemeeter Input`؛ قناة VAIO: A1 وB1 فقط |
| ما يسمعه الإيجنت في Chrome | مدخل الميكروفون: `Voicemeeter Out B1` بشكل صريح |
| رد الإيجنت من Chrome | إخراج Chrome من Volume mixer: `Voicemeeter AUX Input`؛ قناة AUX: B2 فقط |
| ما يصل للعميل | تسجيل Windows والاتصالات: `Voicemeeter Out B2` |
| الميكروفون الحقيقي | مساراته مغلقة أثناء مكالمة الإيجنت لمنع صوت المشغّل والصدى |

إعداد Chrome لا ينطبق على تطبيق ChatGPT لسطح المكتب. أغلق أي فيديو أو تبويب صوتي في Chrome أثناء الاختبار لأن إخراج المتصفح كله يدخل قناة الإيجنت. راجع مستوى الصوت قبل الاتصال؛ إعدادات الصوت الخارجية لا يغيرها التطبيق.

## حدود الوضع الحالي

لا يوجد تكامل برمجي مع Phone Link لاكتشاف الرد أو طلب الرقم أو إنهاء مكالمة الهاتف. تفعيل السماع بعد الرد خطوة يدوية لتجنب الرنين. اكتشاف بداية الكلام يعتمد على تعرف Gemini على الكلام، ولا يضمن تمييز الإنسان من الرد الآلي أو البريد الصوتي؛ التعليمات تطلب تجاهلهما. التطبيق يحجز أول رد صوتي مؤقتاً حتى تصل كتابة كلام العميل، لأن ترتيب أحداث الصوت والكتابة غير مضمون.

حدود التفاوض والهوية حقول في تعليمات النموذج، وليست محرك موافقات مالي أو ضماناً لتنفيذ النموذج لها في كل رد. لا يوجد حجز أو دفع أو إرسال رسائل فعلي؛ أي اتفاق أو خطوة لاحقة يحتاج تنفيذ المشغّل. اختبر المكالمة مع شخص مساعد قبل استخدامها مع العملاء.

## الوضع القديم والنشر والاختبار

«تجربة خدمات أون تراك» يحافظ على قاعدة المعرفة التجريبية والتحية الأصلية وروابط النص. بيانات هذا الوضع غير متصلة بحسابات WHMCS الحقيقية. ملفات `brain.php` و`tts.php` ومسار الصوت القديم ليست مسار Gemini Live الحالي.

انشر ملفات الإصدار كاملة من نفس الفرع، بما فيها `lib/OutboundMission.php` و`assets/outbound.mjs`، مع الحفاظ على ملفات الإعداد المحلية. لا ترفع `tests/` للإنتاج. بعد النشر تأكد من نسخة `0.6.0` في `api/status.php` ثم افتح الصفحة مع تحديث قوي.

اختبارات بدون مفاتيح أو مكالمات مدفوعة:

```sh
node --test tests/outbound.test.mjs
php tests/mission_test.php
php -S 127.0.0.1:8080
# في نافذة أخرى، مع حزمة playwright ومتصفح Chromium مثبتين:
node tests/browser.test.mjs
```

اختبار المتصفح يستخدم خدمة صوت ومدخل صوت وهميين؛ لا يثبت جودة تفاوض النموذج أو وصول الصوت عبر الهاتف الفعلي.
